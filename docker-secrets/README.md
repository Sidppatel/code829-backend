# Docker Compose secrets

Files in this directory are mounted into containers via the compose
`secrets:` block, not via environment variables. `docker inspect` does
not show their contents.

## `redis_password`

Plaintext password for the local Redis container. Generated by the start
scripts (`start.ps1` / `start-backend.ps1`) from the `REDIS_PASSWORD` env
var (sourced from `.env.local`). Do **not** commit — the filename is in
`.gitignore`.

In CI or ad-hoc local runs without the start scripts, create it manually:

```bash
printf '%s' "$REDIS_PASSWORD" > code829-backend/docker-secrets/redis_password
```

```powershell
"$env:REDIS_PASSWORD" | Set-Content -NoNewline code829-backend/docker-secrets/redis_password
```
